# v0.1.0 — scenariusze testów manualnych

- **Tag:** `v0.1.0`
- **Data:** 2026-10-08
- **Poprzednia wersja:** brak (pierwsza wersja)
- **Zakres:** szkielet aplikacji macOS (konfiguracja, logi) oraz tor audio: wybór mikrofonu z przejściem na domyślny, nagrywanie do pamięci z konwersją do 16 kHz mono, przycinanie ciszy. Wszystko dostępne przez narzędzie deweloperskie `va-dev`; aplikacji w pasku menu, transkrypcji i schowka jeszcze nie ma.
- **Migracje / kroki wdrożeniowe:** brak — wersja nie jest jeszcze instalowana z .dmg; uruchamiasz ją ze źródeł.
- **Testy automatyczne:** `cargo test --workspace -- --include-ignored` 49/0 (w tym 3 testy z prawdziwym mikrofonem), `cargo clippy -D warnings` i `cargo fmt --check` czyste. Poniżej wyłącznie to, czego automat sprawdzić nie mógł.

**Oznaczanie wyniku:** `[x]` = sprawdzone i działa · `[-]` = sprawdzone i NIE działa · `[ ]` = niesprawdzone.
**Jeden scenariusz = jeden checkbox** (linia `Wynik N.M` na końcu scenariusza). Przy `[-]` dopisz pod
scenariuszem jedno zdanie: co zobaczyłeś zamiast oczekiwanego.

Scenariusze widać też w Specky (Wersje i eksport → Co nowego), ale **wynik wpisujesz tu**, w `docs/test-scenarios/v0.1.0.md`.

## 0. Przygotowanie

- [ ] Mac z Apple Silicon, Rust zainstalowany (`cargo --version` działa w terminalu)
- [ ] `cargo build -p va-dev` w katalogu repozytorium kończy się bez błędów
- [ ] Co najmniej dwa wejścia audio: wbudowany mikrofon i drugie (słuchawki USB/Bluetooth albo urządzenie wirtualne)
- [ ] Terminal ma zgodę na mikrofon (Ustawienia systemowe → Prywatność i ochrona → Mikrofon) — przy pierwszym nagraniu system o nią zapyta

## 1. Mikrofony

### 1.1 Lista mikrofonów pokazuje wszystkie wejścia i domyślne systemu

**Dlaczego:** nowe — wybór mikrofonu (VA-REC-4) opiera się na tej liście.

**Kroki:**
1. `cargo run -q -p va-dev -- devices`
2. Porównaj z listą w Ustawienia systemowe → Dźwięk → Wejście.

**Oczekiwane:** każde wejście z Ustawień jest na liście; `*` stoi przy tym, które jest zaznaczone w Ustawieniach; `>` przy tym, którego używa aplikacja (bez wpisu w konfiguracji = to samo co `*`).
**Sygnał porażki:** brak któregoś urządzenia, `*` przy innym niż w Ustawieniach albo nazwy z krzakami zamiast polskich znaków.

- [ ] **Wynik 1.1** — zgodne z „Oczekiwane”

### 1.2 Mikrofon wybrany w konfiguracji jest używany do nagrania

**Dlaczego:** nowe — nagranie ma iść z mikrofonu z konfiguracji, nie zawsze z domyślnego.

**Kroki:**
1. W `~/Library/Application Support/VoiceAsystent/config.toml` wpisz `microphone = "<nazwa z listy 1.1, inna niż domyślna>"`.
2. `cargo run -q -p va-dev -- devices` — `>` powinno przejść na wpisane urządzenie.
3. `cargo run -q -p va-dev -- mic-test --seconds 5` i mów do TEGO mikrofonu, potem powtórz, mówiąc tylko do drugiego.

**Oczekiwane:** linia „Nagrywam 5 s z: …” podaje wpisane urządzenie; paski poziomu rosną, gdy mówisz do niego, a zostają niskie, gdy mówisz tylko do drugiego.
**Sygnał porażki:** nagranie idzie z domyślnego mikrofonu albo paski nie reagują na mowę.

- [ ] **Wynik 1.2** — zgodne z „Oczekiwane”

### 1.3 Odłączony mikrofon z konfiguracji → nagranie z domyślnego

**Dlaczego:** nowe — kryterium VA-REC-4; test automatyczny sprawdza logikę na udawanym sprzęcie, nie prawdziwe odłączenie.

**Kroki:**
1. Zostaw w konfiguracji nazwę mikrofonu USB/Bluetooth z 1.2, potem go odłącz.
2. `cargo run -q -p va-dev -- mic-test --seconds 3`

**Oczekiwane:** w logu ostrzeżenie, że wybranego mikrofonu nie ma; „Nagrywam … z:” podaje mikrofon domyślny systemu; nagranie się udaje.
**Sygnał porażki:** błąd i brak nagrania albo próba nagrania z nieistniejącego urządzenia.

- [ ] **Wynik 1.3** — zgodne z „Oczekiwane”

## 2. Nagrywanie i cisza

### 2.1 Granice mowy na prawdziwym głosie

**Dlaczego:** nowe — przycinanie ciszy testowano na głosie syntezatora; prawdziwy mikrofon ma szum tła.

**Kroki:**
1. Usuń wpis `microphone` z konfiguracji (wbudowany mikrofon jako domyślny), w cichym pokoju.
2. `cargo run -q -p va-dev -- mic-test --seconds 6` — milcz ok. 2 s, mów ok. 2 s, milcz do końca.

**Oczekiwane:** linia „Mowa: X–Y s” z X około 1,8 s i Y około 4,2 s (±0,5 s); paski wysokie tylko w czasie mowy.
**Sygnał porażki:** „Sama cisza…” mimo mówienia albo granice obejmujące całe nagranie (szum tła ponad progiem).
**Wynik pomiaru:** poziom szumu tła w ciszy: ____ dB

- [ ] **Wynik 2.1** — zgodne z „Oczekiwane”

### 2.2 Zapis WAV na żądanie daje odtwarzalny plik

**Dlaczego:** nowe — jedyna droga, którą nagranie trafia na dysk.

**Kroki:**
1. `cargo run -q -p va-dev -- mic-test --seconds 4 --save ~/Desktop/proba.wav` i powiedz zdanie.
2. Otwórz `proba.wav` w QuickTime albo Podglądzie (spacja w Finderze).

**Oczekiwane:** plik odtwarza się, słychać Twój głos bez przyspieszenia, spowolnienia ani trzasków; długość około 4 s.
**Sygnał porażki:** plik się nie otwiera, głos jest za wysoki/za niski (zła częstotliwość) albo długość różni się od 4 s.

- [ ] **Wynik 2.2** — zgodne z „Oczekiwane”

## 3. Bariery — te scenariusze mają się NIE udać

### 3.1 Bez `--save` nic nie trafia na dysk

**Kroki:** w pustym katalogu (`mkdir /tmp/va && cd /tmp/va`) uruchom `<repo>/target/debug/va-dev mic-test --seconds 3`, potem `ls -la`, oraz sprawdź, czy w `~/Library/Application Support/VoiceAsystent/` nie przybyło plików audio.

**Oczekiwane:** katalog pusty, brak plików `.wav`/audio gdziekolwiek w katalogach aplikacji (logi w `~/Library/Logs/VoiceAsystent/` są dozwolone i nie zawierają próbek).
**Sygnał porażki:** jakikolwiek plik z nagraniem.

- [ ] **Wynik 3.1** — próba odrzucona zgodnie z „Oczekiwane”

### 3.2 Brak zgody na mikrofon kończy się czytelnym błędem

**Kroki:** w Ustawienia systemowe → Prywatność i ochrona → Mikrofon odbierz zgodę terminalowi, uruchom ponownie terminal i `cargo run -q -p va-dev -- mic-test --seconds 2`. Na koniec przywróć zgodę.

**Oczekiwane:** komenda kończy się błędem albo nagraniem samej ciszy („Sama cisza…”) — bez zawieszenia ani awarii. Czytelny komunikat z instrukcją powstaje dopiero w aplikacji (zadanie 5.5); tu sprawdzamy tylko, że nic się nie wysypuje.
**Sygnał porażki:** zawieszenie, panika (`panicked at`) albo nagranie z dźwiękiem mimo braku zgody.

- [ ] **Wynik 3.2** — próba odrzucona zgodnie z „Oczekiwane”
